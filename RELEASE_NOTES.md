# Reel 1.1.0

## Highlights

- Smoother carousel motion and trackpad handling
- Continuous arrow-key navigation with reduced input friction
- Bounded thumbnail cache to keep memory use controlled
- Thumbnail work cancelled when the picker closes
- Reduced background work when idle
- Apple-silicon (arm64) release target
- Display-only wallpaper labels: number, filename, or hidden
- New dark, minimal Reel visual identity

## Distribution

The intended distribution artifact is an Apple-silicon DMG generated from the release project.

## Verification note

The source project was validated for Swift syntax in the development environment. Final app compilation must be performed with Apple's macOS SDK on an Apple-silicon Mac.
